# PopOut Connect Four

This project was developed for the FCUP Artificial Intelligence course. It
includes a playable version of PopOut Connect Four and an analysis comparing
different AI approaches to the game.

PopOut is a Connect Four variant where each player can:

- `drop` a piece into a column
- `pop` their own piece from the bottom of a column

The game and analysis include:

- **MCTS**, which chooses moves by simulating possible games
- **MoveMCTS**, a more efficient MCTS that stores moves instead of full boards
- **Minimax** with alpha-beta pruning
- **Hybrid MCTS**, combining MCTS with Minimax evaluation
- **ID3 decision trees** trained from moves generated by MCTS

## Requirements

- Git
- Python >= 3.11

## Setup

```bash
git clone https://github.com/andredpinto/AI_2526_Project.git
cd AI_2526_Project
python -m pip install -r requirements.txt
```

## Play

Run from the project root so the pre-trained ID3 trees are found correctly:

```bash
python main.py
```

The menu supports human vs human, human vs computer, and computer vs computer.
Moves use columns 1 to 7:

```text
drop 4
pop 3
```

## Notebooks

From the project root, install the additional analysis dependencies:

```bash
python -m pip install -r requirements-notebooks.txt
```

Open the notebooks any way you want:

- [MCTS and Minimax analysis](notebooks/analysis_mcts.ipynb)
- [ID3 decision-tree analysis](notebooks/analysis_id3.ipynb)

When running them locally, use `notebooks/` as the working folder so the
relative paths work correctly. Saved results are included, and new results may
vary because some algorithms are stochastic.

## Project structure

- [`main.py`](main.py): interactive game menu
- [`game/`](game/): board rules, game loop, MCTS, MoveMCTS, and Minimax
- [`decision_tree/`](decision_tree/): ID3 implementation and pre-trained trees
- [`data/`](data/): datasets used to train and test ID3
- [`notebooks/`](notebooks/): explanations, experiments, and results
- [`scripts/`](scripts/): decision-tree training utilities

## Retrain ID3

Pre-trained trees are already included, so this is not required to play. To
train them again, run from the project root:

```bash
python -m pip install -r requirements-notebooks.txt
python scripts/train_id3.py
```

This uses `data/dataset_mcts.csv` and overwrites the models in
`decision_tree/pre_trained_trees/`.
